5. Module 4: Cost Management & Earned Value Management (EVM)

5.1 EVM Mathematical Baseline & Formulas

Earned Value Analysis was performed strictly adhering to PMI standards as of the Status Date (October 26, 2026 / Week 8). The formulas applied are defined as follows:

  • Planned Value (PV): $\sum (\text{BAC}_i \times \text{Planned \% Complete}_i)$
  • Earned Value (EV): $\sum (\text{BAC}_i \times \text{Actual \% Complete}_i)$
  • Actual Cost (AC): Sum of all actual expenditures incurred to date
  • Cost Variance (CV): $\text{EV} - \text{AC}$ (Negative indicates Cost Overrun)
  • Schedule Variance (SV): $\text{EV} - \text{PV}$ (Negative indicates Behind Schedule)
  • Cost Performance Index (CPI): $\frac{\text{EV}}{\text{AC}}$ (Threshold: $\ge 1.00$)
  • Schedule Performance Index (SPI): $\frac{\text{EV}}{\text{PV}}$ (Threshold: $\ge 1.00$)
  • Estimate at Completion (EAC): $\frac{\text{BAC}}{\text{CPI}}$
  • Variance at Completion (VAC): $\text{BAC} - \text{EAC}$
  • To-Complete Performance Index (TCPI): $\frac{\text{BAC} - \text{EV}}{\text{BAC} - \text{AC}}$
